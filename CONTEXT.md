# Transcribe

Локальный офлайн-конвертер аудио/видео в размеченный текст: распознавание речи (ASR), разделение по спикерам (диаризация) и сборка артефактов для чтения ИИ-агентами. Источники — локальные медиафайлы и YouTube.

## Language

### Прогон (run)
Одно выполнение `transcribe <источник>`: от подготовки аудио до записи артефактов. Жизненный цикл виден через progress.json.
_Avoid_: задача, сессия, job

### Источник (source)
Вход прогона: локальный медиафайл или YouTube-ссылка.
_Avoid_: файл, вход, URL

### Подготовка источника (source prep)
Внутренний шов run-модуля: источник → папка вывода + audio_16k.wav. Владеет ветвлением локальный/YouTube, именованием папки и цепочкой yt-dlp/ffprobe/ffmpeg; ошибки — RunError.
_Avoid_: препроцессинг

### Движок (engine)
Внешняя система распознавания (FluidAudio Parakeet + pyannote-диаризация), с которой общается только движковый шов.
_Avoid_: бэкенд, модель, ASR-сервис

### Транскрипт (transcript)
Канонический текст прогона: размеченные реплики по спикерам. Читается агентами из transcript.md.
_Avoid_: стенограмма, выжимка

### Слова (words)
Распознанные слова с таймкодами: start, end, text. Базовый материал для сборки реплик.
_Avoid_: токены, wpm

### Реплика (turn)
Непрерывная группа слов одного спикера: speaker, start, end, text. Единица чтения транскрипта.
_Avoid_: абзац, блок, фраза

### Спикер (speaker)
Участник записи, помеченный стабильной меткой S1..Sn по порядку первого появления.
_Avoid_: голос, участник, person

### Диаризация (diarization)
Отделение речи спикеров друг от друга по сегментам.
_Avoid_: разделение, сегментация

### Язык (language)
Метка ru | en | mixed | auto, разрешаемая цепочкой: явный аргумент > ответ движка > эвристика по тексту.
_Avoid_: локаль, locale

### Стадия (stage)
Этап прогона, видимый в progress.json: prep (конвертация), asr, diar, merge. Стадии asr/diar объявляет движок через live-канал; prep/merge — владелец прогона.
_Avoid_: фаза, шаг, пайплайн-статус

### Артефакты (artifacts)
Выход прогона: transcript.md, transcript.json, manifest.json, progress.json.
_Avoid_: выходные файлы, результаты
